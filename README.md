# INGLŌ KŌRE — Website

Sitio web oficial de la app INGLŌ KŌRE.

## Estructura

```
src/
  layouts/
    Layout.astro        # Layout base (nav + footer)
  pages/
    index.astro         # Landing page principal
    privacidad.astro    # Política de privacidad
    terminos.astro      # Términos y condiciones
public/
  icon.png              # Ícono del León
```

## Desarrollo local

```bash
npm install
npm run dev
```

## Deploy en Vercel

1. Sube este proyecto a GitHub
2. Ve a vercel.com → New Project
3. Importa el repositorio
4. Vercel detecta Astro automáticamente
5. Click Deploy

## Páginas

- `/` — Landing page
- `/privacidad` — Política de privacidad  
- `/terminos` — Términos y condiciones
